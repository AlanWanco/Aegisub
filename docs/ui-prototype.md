# wxWidgets 界面原型与倍速播放

此分支沿用原有 wxWidgets、C++ 文档模型、媒体后端和 Lua Automation。视觉修改集中在 `src/ui_theme.h` 与工作区控件，倍速逻辑集中在播放控制器及音频提供者包装层。

## 试用本机原型

已经编译并打包的本机版本位于 `build-ui/Aegisub.app`。使用独立配置启动：

```sh
./tools/preview-ui.sh build-ui build-ui/ui-preview.ass
```

也可以省略字幕路径，启动空白文档：

```sh
./tools/preview-ui.sh build-ui
```

启动器将配置、缓存与自动保存写入 `build-ui/preview-home`，首次使用时创建配置，后续保留其中的设置。演示字幕和视频仅在本机构建目录中。直接打开 `.app` 会使用常规 Aegisub 配置，建议通过上述脚本试用。

## 界面改动

- 统一主工作区底色、选中态和网格线。常用工具使用统一 SVG 线性图标；没有 SVG 支持的 wxWidgets 构建会使用同一路径生成的 1×/2×浅色、深色 PNG，图标不依赖系统外部文件。
- 增加面板留白、表格行高和字幕文本行间距。
- 窄窗口下，格式工具按钮栏会移到编辑区的下一行；保留原有命令和输入控件。
- 提供跟随系统的浅色与深色配色。历史默认颜色会映射为新配色；与历史默认值不同的用户颜色保持原值。显式选择了历史默认颜色的设置无法与未修改设置区分，也会映射。

原生控件仍遵循系统外观；对话框、频谱配色及其他专业工具未全部重新设计。
左侧视频工具栏和矢量剪裁子工具使用青绿色实底、对比图标标示当前选择，避免只依赖淡灰系统状态。

## 倍速播放

视频与音频播放区都有倍率选择，两个选择器同步显示。视频、音频菜单中也有“播放速度”子菜单。

支持 `0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x`、`2x`。支持播放中切换、单句播放和音频选区播放。倍率属于当前窗口，不写入字幕，也不在重启后保留。

当前实现通过线性插值改变音频速度，音调会随之改变，未实现保持音调的时间拉伸。`1x` 直接读取原始音频。波形、频谱、音频导出和字幕时间码使用原始数据。

可在偏好设置中为以下命令绑定快捷键；没有覆盖现有快捷键：

- `video/playback/rate/increase`：下一档更快速度。
- `video/playback/rate/decrease`：下一档更慢速度。
- `video/playback/rate/100`：恢复正常速度。
- `video/playback/rate/50`、`75`、`125`、`150`、`200`：固定倍率。

播放中切换会停止并重新创建音频输出，从当前时间继续，可能出现短暂间隔。视频播放时以同一个源时间位置重新锚定两个流；未做硬件回录验证。

## 维护边界

`libaegisub/audio/provider_rate.cpp` 只包装传给播放器的音频，项目原始 provider 不变，因此无需分别修改各平台音频后端。构建配置修改前的备份保存在本机 `build-ui/backups`。应用包和截图属于本机构建产物，不应提交。


## GPUI 工作区实验

从 Aegisub 的“视图 → GPUI Workspace Prototype...”可启动独立 GPUI 窗口。原型通过仅绑定回环地址的临时 TCP 端口和每次启动随机令牌连接当前 `agi::Context`；文档与操作请求在 wx 主事件循环处理。字幕行、选择状态、保存状态和视频帧来自当前 C++ 项目，GPUI 的字幕文本编辑会提交为 Aegisub 撤销栈操作。视频帧由 `AsyncVideoProvider` 异步生成并返回，未引入第二个解码器。

GPUI 目前已接入当前 C++ 文档的多选字幕列表、文本/属性批量编辑、格式与复制粘贴、覆盖粘贴、撤销/重做、完整 ASS 样式与样式库、脚本属性、翻译/样式助手、查找替换/条件选行、附件管理、时间平移/后处理和分辨率重采样。命令目录来自运行时注册表，菜单来自平台/用户合并配置；动态 Lua 宏在同一项目执行。

工作台采用石墨灰/雾灰两套配色与蓝紫强调色，左侧按工作区、字幕工具、项目设置分组导航；左上角按钮可手动折叠为图标栏或展开文字导航，当前窗口会保留手动选择；未选择时按窗口宽度自动适配。图标有可访问名称，导航和属性区可滚动。顶部保留菜单和文件操作；视频正下方放置播放/暂停、逐帧与时间轴控制，之后依次为文本编辑区和字幕列表，右侧按时间/字幕/边距组织属性。文本编辑标题与当前字幕文件名同一行显示。工作区与属性面板之间有可拖动分隔条，属性面板标题栏的减号/加号按钮可无指针微调宽度；字幕编辑区与字幕列表之间同样有分隔条，并由上下按钮微调高度。Lucide 图标随应用打包；视频倍率、刷新帧和四向平移收进菜单，保留复位与安全区按钮。字幕默认颜色跟随工作台主题，自定义字体与颜色继续使用共享配置。

音频页复用原有波形/频谱渲染、时间标记/手势、播放、卡拉 OK 分割和提交控制。视频页提供帧/时间跳转、空白视频、显示比例和媒体详情；时间轴及七种视觉排版工具操作原有控制器并写回 ASS。视频框倍率与原命令/菜单同步，画面缩放和平移另有倍率、复位及四向菜单，滚轮使用共享偏好。安全区按钮沿用电视过扫描两层圆角遮罩及原配置，按缩放和平移后的图像区域绘制。音频剪辑、关键帧和时间码使用 GPUI 原生文件选择器及既有写入器，已核对 WAV 采样、关键帧/VFR 往返和 CFR 视频帧数。

文件页可指定编码打开和恢复旧版本。编码选项来自当前 iconv，检测值只作提示；可手选 GB18030、Shift-JIS、UTF-16/32 等。修复通用 UTF-16/32 遇到 BOM 时换行字节序不一致的问题，大小端均已回归。恢复列表和旧版窗口共用配置目录扫描、文件名分组和时间排序，提供自动保存、原始备份、异常恢复三类版本。

设置页提供本机构建可用的 143 个偏好项和 125 条初始快捷键绑定：分类/搜索、草稿、应用/放弃、恢复默认、类型/范围校验及写入前配置备份。主题与工具栏即时同步，字体/颜色、软换行及音频渲染设置使用共享配置；尚未接入的 GPUI 控件行为会标注。快捷键支持录入、绑定/移除、冲突检查/显式替换及默认恢复。桌面实测新绑定立即触发并跨重启保留；也修复了热键变动时 macOS 全局菜单缺少文档上下文导致的崩溃。

本机验证：`cargo +1.95.0 fmt --manifest-path gpui-prototype/Cargo.toml`、`cargo +1.95.0 check --manifest-path gpui-prototype/Cargo.toml -q`、release 测试/构建和 Aegisub macOS arm64 增量构建通过。拼写、偏好和文件工具协议回归通过；桌面已检查拼写候选词/个人词典添加与移除、偏好搜索/主题下拉和即时切换、快捷键录入与移除、恢复版本筛选/打开。每项协议回归和桌面证据记在 [GPUI 移植计划](gpui-migration-plan.md)；脚本、结果 JSON、截图、日志和独立配置位于忽略的 `build-ui-gpui/`。

Windows、Linux、wxWidgets 3.2、中文输入法预编辑/候选框仍未实机验收；不能用 macOS 测试或历史 Windows CI 代替。原生导出/过滤器、Kanji 定时、Lua 对话框/进度，以及部分视频/窗口/偏好控件仍待迁移。拼写复用平台工厂，本机实际验证的是 macOS 系统服务；Hunspell 构建尚未实测。关联媒体/脚本信任、未保存确认和剩余兼容对话框可能进入 wx 模态循环，此时桥接等待不等于崩溃。GPUI 依赖 Rust 1.95，本机默认 Rust 1.93.1 无法编译当前 `gpui-pre`。

联调期间还修复了 GPUI 打开视频时的初始化时序：视频 provider 创建后，先将字幕副本排入其工作队列，再发送 provider 已打开通知和显示视频属性对话框，避免嵌套事件循环先处理帧请求。


### 功能与验证边界

偏好设置读取旧配置定义的动态选项并先校验整批修改，写入前备份；搜索、主题下拉、即时应用/主题切换已桌面验证。其余带“仍待移植”说明的偏好只证明设置值可以保存，不能视为对应 GPUI 控件行为已经实现。快捷键复用旧命名和上下文冲突约定；桌面已验证组合键录入、保存、空命令屏蔽和移除，已有独立回归覆盖显式冲突替换和持久化。

拼写检查调用共享 `SpellChecker` 工厂：macOS 使用系统拼写服务，其他启用 Hunspell 的构建使用 Hunspell。按 ASS 字幕词法单元过滤标签和绘图，可替换、忽略、批量替换并撤销，也可管理个人词典。本机回归覆盖替换、过滤、UTF-8 字节位置、过期文本保护与撤销，桌面验证建议、添加和确认移除个人词。系统个人词典独立于预览 profile；已核查并清理已知测试词 `speling`、`wrold`，未声称全局词典恢复。文件工具提供按指定编码打开和自动保存/备份/异常恢复列表；恢复项按文件名分组、按时间排序后交给同一字幕文档打开，桌面验证筛选恢复组、选取最新版本并打开。

视频缩放/平移已在真实窗口核对 `\pos(720,400)` 和 `\clip(320,120,960,520)` 的精确写回及单次撤销；适应布局的整数画布误差在一个逻辑像素内。修复了固定图像尺寸时调整窗口导致拖动使用新原点继续写入的问题，窗口变化、视口外但窗口内松开及滚轮期间取消已桌面回归。中键合成事件没有产生可用的移动事件，反向/水平滚轮及交换轴/不操作的扩展回归因焦点切换未完成，仍需桌面验收。

安全区新增两项几何测试，覆盖中心不遮挡、边缘遮罩、宽高比阈值及缩放/平移；当前七项 Rust release 测试全部通过。共享命令的开关、菜单、无视频拒绝及媒体切换协议回归通过；本轮实际窗口已验证安全区按钮切换，并检查宽屏视频上的两层圆角叠层，其余比例和缩放组合仍待桌面验收。最新运行时目录为 334 条，其中原生入口 78 条、共享操作 219 条、Lua 宏 7 条、兼容对话框 13 条、依赖旧控件 16 条、内部入口 1 条；入口分类不代表完整工作流覆盖率。
